# Система відстеження елементів зображення на мікроконтролері Raspberry Pi

> Програмна система для аналізу відеопотоку в режимі реального часу та дослідження методів комп'ютерного зору на платформі Raspberry Pi 5.

* **Операційна система**: Raspberry Pi OS

---

## Опис функціоналу

Система забезпечує:

* отримання відеопотоку з камерного модуля Raspberry Pi;
* обробку кадрів у режимі реального часу;
* виявлення елементів зображення різними методами комп’ютерного зору;
* дослідження contour-, corner-, blob- та ridge-методів;
* використання HOG-дескриптора для покращення якості виявлення;
* оцінювання ефективності алгоритмів;
* розрахунок показників Precision, Recall, F1 Score та Accuracy;
* визначення швидкодії алгоритмів та FPS системи;
* формування статистики та графіків результатів.

## Як запустити проєкт

### 1. Підготовка системи

Оновлення Raspberry Pi OS:

```bash
sudo apt update
sudo apt upgrade -y
```

### 2. Встановлення залежностей

```bash
sudo apt install -y python3
sudo apt install -y python3-pip
sudo apt install -y python3-opencv
sudo apt install -y python3-numpy
sudo apt install -y python3-flask
sudo apt install -y python3-pil
sudo apt install -y python3-matplotlib
sudo apt install -y python3-picamera2
```

### 3. Запуск програм

Базові методи:

```bash
python3 basic_cv_methods_system.py
```

Система профілів:

```bash
python3 method_profiles_system.py
```

Комплекс із 12 методів:

```bash
python3 multi_method_analysis_system.py
```

Система з використанням HOG:

```bash
python3 hog_enhanced_detection_system.py
```

## Проблеми і рішення

| Проблема                        | Рішення                                                             |
| ------------------------------- | ------------------------------------------------------------------- |
| Камера не визначається системою | Перевірити підключення камери та виконати команду `libcamera-hello` |
| Не запускається OpenCV          | Перевірити встановлення пакета `python3-opencv`                     |
| Не відкривається вебінтерфейс   | Перевірити роботу Flask-сервера та мережеві налаштування            |
| Низький FPS                     | Зменшити навантаження на систему або використовувати швидші методи  |
| Помилки імпорту бібліотек       | Перевірити встановлення необхідних пакетів через `apt`              |
